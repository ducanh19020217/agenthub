# AgentHub 2.1.0

Bản cập nhật tập trung vào hiệu năng daemon: event loop không còn bị chặn bởi các thao tác git và hệ thống file, web và API phản hồi nhanh hơn, tốn ít bộ nhớ hơn.

## Tính năng mới

- **Warm worktree pool**: giữ sẵn worktree đã chuẩn bị để task khởi động nhanh hơn; bật/tắt và cấu hình trong Settings.
- **Bảng tiến độ worker**: trang chi tiết task hiển thị số commit, file đã đổi và hoạt động gần nhất khi log của worker thưa hoặc trống.
- **Số liệu hiệu năng daemon**: `/api/status` và dashboard hiển thị độ trễ event loop cùng bộ nhớ (heapUsed, rss, external).
- **agy stream-json**: worker agy xuất log dạng stream-json mặc định, theo dõi tiến độ chính xác hơn.
- **Nén phản hồi API**: hỗ trợ gzip và brotli.

## Cải tiến & sửa lỗi

- Chuyển các thao tác git và worktree trên đường đi của daemon (dọn worktree, kiểm tra trùng file, snapshot tham chiếu, checks) sang bất đồng bộ; giới hạn số lệnh git chạy song song.
- Sửa lỗi web/API treo hàng chục giây khi có worktree hết hạn còn thay đổi chưa commit: daemon chỉ kiểm tra lại sau 30 phút thay vì mỗi tick.
- Giảm tải truy vấn API và dọn dữ liệu cũ theo lô; web gộp làm mới dữ liệu từ SSE và tạm hoãn khi tab bị ẩn.
- `/api/status` không còn tính dung lượng worktree; đọc phần cuối log thay vì cả file; không đọc lại transcript Claude không đổi.
- Lệnh `agenthub mcp` khởi động nhẹ hơn, không nạp daemon và các module nặng.
- Tinh chỉnh cấu hình malloc của systemd unit, giữ nguyên biến môi trường người dùng tự thêm.
- `hub_task` hiển thị đúng thời lượng và số lượt chạy.
- Xoá project không còn chặn daemon.

