01 — The why

Một nơi để giao việc,
một vòng lặp để ship.

AgentHub quản lý hàng đợi, quota, worktree và reviewer để các project chạy đều mà không cần thêm một tab terminal.

02 — The loop

Từ yêu cầu đến
code đã được duyệt.

01✦

Giao việc

Web, Telegram hoặc MCP. AgentHub nhận task theo project.

02↗

Chia và thực thi

Bộ não chia task; worker Gravity/Codex/Gemini/Claude làm trong worktree riêng.

03✓

Autocheck

Lint, typecheck, test, build và quy ước commit chạy trước review.

04◈

Duyệt và hợp nhất

Codex duyệt; Claude thay khi Codex bận/hết quota, làm trọng tài khi bị trả lại nhiều lần. Rồi tự merge, self-deploy.

03 — What ships in v2

Mọi thứ cần cho
một đội AI đáng tin.

Các tính năng dưới đây đã có trong AgentHub v2.

↗

Tự duyệt, tự merge

Autocheck xong thì reviewer duyệt code và hub tự hợp nhất vào nhánh tích hợp.

↯

Chuỗi model, nhiều tài khoản

Fallback giữa model, engine và profile khi quota bận hoặc hết.

◎

Bộ não theo project

Claude hoặc Codex nắm context project, chia việc và review qua MCP.

⌘

Phòng ban

Nhóm project, tài khoản, giới hạn và bộ não theo phòng; chia lượt công bằng.

◌

Chế độ tập trung

Ưu tiên một project khi cần dồn tài nguyên để ship nhanh.

⌁

Telegram theo project

Topics tách theo project/phòng ban, kèm trợ lý toàn quyền tùy chọn.

⑂

Quy ước commit theo project

externalRef và autocheck commit message giữ lịch sử sạch.

⏻

Tắt/bật an toàn

agenthub stop/start, nút web hoặc /shutdown; task đang chạy được resume.

≋

Thông báo gọn

Chống trùng và chỉ báo khi task thật sự tắc, hết quota hoặc cần người duyệt.

▱

Quản lý tài nguyên

Load guard, dọn worktree/rác tạm và hỗ trợ worktree trên ổ đĩa riêng.

↓

Bộ cài một dòng

Linux glibc ≥ 2.31; macOS tự tải Node, không cần Xcode Command Line Tools.

⌬

Kết nối OpenProject

Nhận, triage và đồng bộ ticket OpenProject hai chiều, kèm bảng giờ và báo cáo ngày tự động.

⇄

Giao việc qua merge request

Đồng bộ Gitea, tự tạo và merge PR theo cấu hình từng project; kèm remote deploy riêng.

07 — FAQ

Câu hỏi
thường gặp.

AgentHub có gọi API Claude trực tiếp không?

Không. Bộ não là Claude Code hoặc Codex đang chạy trên máy; AgentHub điều phối qua CLI và MCP.

Tôi có cần nhiều tài khoản không?

Không bắt buộc. Nhiều profile giúp fallback và dùng quota song song.

Code có rời khỏi máy tôi không?

AgentHub chạy local. Dữ liệu và quyền truy cập model tuân theo CLI/provider bạn cấu hình.

AgentHub đã kết nối OpenProject và giao việc qua merge request chưa?

Có, từ v2. Đã hỗ trợ đồng bộ hai chiều OpenProject (ticket, triage, bảng giờ, báo cáo ngày) và giao kết quả qua merge request trên Gitea kèm remote deploy riêng từng project. Jira đang được phát triển tiếp.
